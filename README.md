# SmileCare Dental Clinic Website

A multi-page responsive dental clinic website starter.

## Pages
- Home
- About
- Services
- Service Details
- Doctors
- Doctor Profile
- Appointment Booking
- Gallery
- FAQ
- Contact

## Before going live
1. Replace demo images in `/images/` with the clinic's real photos.
2. Change the clinic name, address, email and phone number.
3. Change the WhatsApp number in `index.html`, `appointment.html`, and the floating button.
4. The appointment form is currently front-end only. Connect it to a backend, Google Sheets/Form service, email service, or CRM for real bookings.
5. Replace the Google Maps search link with the clinic's actual Maps listing.

## Run
Open `index.html` in VS Code with Live Server, or upload the whole folder to your hosting provider.
